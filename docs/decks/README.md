# Presentation decks

Plain-language slide decks explaining the lab, for mixed / semi-technical audiences. Same visual style across all three parts.

| File | What it is |
|---|---|
| `5g-lab-overview.pptx` | **Part 1 — the big picture.** What a 5G network is, what's installed, how a phone gets online. |
| `5g-architecture-walkthrough.pptx` | **Part 2 — reading the architecture diagram** (`../diagrams/5g-architecture.svg`): colors, RAN, control plane, UPF, the two end-to-end journeys. |
| `5g-attack-flow-walkthrough.pptx` | **Part 3 — reading the attack-flow diagram** (`../diagrams/5g-attack-flow.svg`): inject → tap → parse → score, and the five attacks with their tells. |
| `5g-lab-field-guide.pptx` | **All three parts stitched into one** deck (25 slides) with a title, contents, and section dividers. |
| `5g-lab-speaker-notes.docx` | Per-slide **speaker notes** keyed to the field guide (and the three standalone decks). |

Diagrams live in [`../diagrams/`](../diagrams/); the plain-language write-ups they're based on are in the project docs.
